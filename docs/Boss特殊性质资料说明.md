# Boss 特殊性质与历史回路资料说明

本次于 2026-11-17 整理游戏内历期矩阵的18个关卡，以及这些关卡出现的 Boss 对应的怪物描述。所用资料文件标记为3.8；未进入矩阵的 Boss 不收录。

关卡 ID 2、4 原活动名为“矩阵叠兵”，按作者自行命名分别归为 S0-1、S0-2；ID 6 为终焉矩阵 S1-1。其余阶段沿用来源阶段名。

## 特殊性质范围

收录影响玩家对 Boss 输出的伤害增减，以及理解这些增减伤所必需的触发条件。例如无铭探索者的层数上限、附加集谐条件与每层4%易伤共同保留；炉芯机骸的核心暴露、破甲条件与异常效应增伤共同保留。纯闪避限制、防护、无敌和与输出无关的行动说明不显示。普通常驻属性抗性不混入特殊性质列表。

辛吉勒姆的25%减伤经作者确认为此前遗漏，现与怪物自身描述的迷航机制合并，适用于其历期矩阵记录。此前未补齐的怪物描述已核对，包括无铭探索者、海维夏、炉芯机骸、万囮牢·朽躯；既有封庭械囿、天傀劫煞、达妮娅等说明也复核了来源。怪物描述取自本次核对的当前资料，不冒充历史网页快照。

仅有辅助说明、没有确认伤害机制，或矩阵标题与描述的怪物名称不一致时继续留空，不认定为“已确认没有机制”。按作者于2026-11-18确认，同种Boss在各期的伤害性质同步，现为24条阶段/Boss有说明记录、22条空白记录。有正文的内容合并为11组性质；界面默认连同空白性质一起列出，空白项按作者指定显示“无特殊增伤性质”。该显示文字不改变配置中的待补状态。

## 配置与来源

- `config/boss_properties.json`：按期数保存性质与来源；`specialProperties: []` 为留空待补。`monsterSources` 保留怪物描述来源及明确摘录，`propertyEvidence` 保留矩阵原文及对应波次。
- `data/boss_property_sources.json`：18个关卡及对应怪物描述的核对记录，包含未显示的辅助说明。
- 当前可排布的 S2-3、S2-4 以 `config/seasons/` 对应文件的 `specialProperties` 为准。其他期数手动补充资料库时，填写性质并将 `propertySource` 设为 `user-confirmed`、`status` 设为 `confirmed`，同时指定有效的本地头像。
- `python tools/sync_boss_properties.py` 从缓存重新整理；`--refresh --data-version 3.8` 重新抓取对应公开数据。仅采用脚本中明确核对的摘录，保留人工确认内容，未知描述需核对后再收录。
- `config/matrix_references.json`：九期共36条回路增益，包含参数替换后的说明、原始参数、图标与来源。`python tools/sync_matrix_references.py` 从已抓取的矩阵快照生成，并下载缺少的回路图标。

## 回路查看与排布隔离

左上角“体力期数”中的历史期数只有查阅用途。它们不含分数、血线、体力或队伍配置，不修改存档，不出现在新建方案中。页面刷新或切换排布后恢复查看当前方案的体力期数。当前两期选择仍采用原体力冲突检查，并显示对应增益。血线期数始终由排布方案决定。

## 2026-11-18 截图与文字补正

`config/boss_property_overrides.json` 保存本次手动确认的替换内容，生成脚本在跨期同步前应用，防止重新整理后恢复已删除文字。朔雷之鳞加入集谐条件20%增伤、干涉上限+2及每场一次的额外2层机制；伤痕加入聚爆效应100%增伤；炉芯机骸只保留截图未划去的异常效应增伤段。

矩阵集群是波次统称，按实际阵容使用独立的 `propertyGroup`，不参与同名Boss跨期同步。S1-3采用游戏中冥渊守卫（320000070）的图鉴头像，S2-1采用奏谕乐师（320000040）的图鉴头像，下载地址与哈希保存在条目中。S2-1的性质以用户最新截图更正为准：敌方所受到的湮灭伤害最终提升10%，当受虚湮效应影响时，该效果提升至40%。不收录敌方攻击力提升50%的部分。
